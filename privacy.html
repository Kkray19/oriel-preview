Privacy

What is collected, and where.

There are three different things here, kept apart on purpose: this website, the app, and — not yet live — buying the app.

This website

  • No analytics, no session replay, no advertising or tracking scripts.
  • No cookies. Fonts and pictures are served from this site itself, with no third-party requests.
  • One preference is kept in your browser’s local storage if you use the “Pause motion” switch. It never leaves your browser.
  • Whoever hosts this site will see ordinary server logs (such as IP address and the pages requested). Which host that is hasn’t been decided; this page will name it.

The app

  • No account, no subscription, no licence server and no telemetry.
  • Network access only to the named hosts listed in the table on the home page, each behind its own switch; its network client refuses every other address in code.
  • Calendar, Reminders, session files, the clipboard and and AI session files are read on your Mac. Nothing in them is uploaded by Oriel.

These statements are the app’s own documentation for version 0.5.1 and its internal security notes, not an independent certification.

Buying Oriel (not yet live)

Payment will be handled by a payment provider that hasn’t been chosen. Before any order can be placed, this page will say which provider, what personal data it and this site collect (for example an email address and payment details), why, how long it is kept, and how to ask for it to be deleted. Until then, this website collects none of it: there is no email form and no order form.

That is separate from the app: buying the app does not add an account, and the app will not need to contact a licence server to run.
