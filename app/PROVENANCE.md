# Provenance of the pictures in this folder

Every `.webp` here is a **genuine render of the LocalNook app drawn with fictional data**.

- **How they were made:** the app's own sealed preview renderer, run from the native repository on 2026-10-12:
  `LocalNook --render-preview <dir> --preview-width 720 --preview-only <scene,…>`
  (scenes: `dashboard-caffeinate-agents`, `ai-dashboard`, `tray-populated`, `tray-drag-target`, `tools`, `calendar-tool`, `timers-tool`, `devices-tool`, `closed-agent-claude`, `closed-timers`; added 2026-10-12 for the live-activities scene: `closed-media-bars`, `closed-media-peek`, `closed-hud-volume`, `closed-hud-brightness`, `closed-caffeinate-agents`, `closed-eyebreak`, `closed-agent-openai`; and for the hands-on demos: `closed-media-peek-paused`, `-peek-pressed`, `-wave`, `-dots`, `-pulse`, `-ring`, `closed-hud-muted`, `-brightness-low`, `closed-agent-mixed`, `closed-agent-orb-max-orbits|globe|wave|ring|web`, `closed-caffeinate`, `-until`, `-until-expanded`, `-agents-finished`). Hotspot positions in the demos were measured from these files' pixels.
  A sealed run uses a throwaway preferences suite and its own support folder, refuses every network, permission and keychain call, and draws invented figures. No real session, calendar, clipboard or file content was read.
- **Binary:** the native repository's SwiftPM release build (`.build/release/LocalNook`, reports `dev / unpackaged`, built 2026-10-10 23:54 from `main` in the 0.5.x line; `VERSION` reads 0.5.1). It is *not* a notarized release build. Re-render from the exact release commit before launch.
- **Camera framing:** the live-activities scene zooms and pans a *camera* over these whole files (CSS transform) and never frames beyond them; the files themselves are unchanged. The black morphing shape between states is the site's own drawing, measured from the renders' notch geometry (standard 557–1067 × 64 px, wide 557–1603 × 64, peek 557–1067 × 200), and is fully transparent once each state settles, so only genuine pixels remain visible at rest.
- **Processing:** the 2× PNG masters (`../../assets-src/*.png`, SHA-256 in `assets-src/SHA256SUMS`) were converted with `cwebp -q 92 -m 6`. Nothing was cropped, recoloured, retouched or composited; dimensions are unchanged (1624×464, and 1624×788 for the AI sessions page).
- **Wallpaper and menu bar:** the purple gradient and the menu-bar strip are the renderer's own stand-in desktop, not a real wallpaper.
- **Still on-screen fixtures worth a human glance before launch:** the media rows name real songs and artists (titles only, invented playback state); the Devices render shows a device called "Studio AirPods Pro 2" and Apple's symbol for it (see docs/LAUNCH_READINESS.md, "Apple marks").
- **Not used on purpose:** `~/Desktop/LocalNook-acceptance/*.png` (acceptance screenshots that may contain a real session list) and `~/Downloads/LocalNook-24-second-preview.mp4` (unknown provenance). They were never opened.

- **AI dashboard explorer (2026-10-12):** `ai-*.webp` are the sealed renderer's scenes `ai-dashboard`, `-middle`, `-end`, `-period`, `-list`, `-today`, `-today-hour`, `-today-hour-tokens`, `-today-calendar`, `-today-picked`, `-activity`, `-activity-day`, `-activity-day-dollars`, `-activity-week`. The renderer draws the drill-downs from a different invented snapshot than the main dashboard, so figures differ between views; the site says so.
